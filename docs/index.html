Pictures are read from the archive beside this repository, through the ignored images link — run code/downloadImages.py to fill it. A card whose picture has not been downloaded, or whose source publishes none, is drawn from its own record instead. Open this page over a local server (python3 -m http.server from the repository root, then /docs/) so the browser is allowed to read them.

Japanese, Traditional Chinese and Korean come from the official Pokémon card sites; English from pkmncards; TCG Pocket from limitlesstcg. French, German, Spanish, Italian, Portuguese and Simplified Chinese have no official database to read, so they come from the community TCGdex API — every one of those cards names it under sources, and older sets there often publish no picture, Simplified Chinese none at all. This page carries the searchable index; the complete stored record for each card lives in the repository as data_<lang>/<set>/<card>.json.
